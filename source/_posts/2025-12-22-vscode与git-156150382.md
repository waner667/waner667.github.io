### 几点问题：

#### 问题1：配置ssh密钥时，怎么都连接不了github，设置用https都不行

（dy视频1）

ssh: connect to host github.com port 22: Connection timed out

解决办法：由于我用的是公司的网，后换成流量就可以了。

另：终端快捷键CTRL+',或者直接找terminal-->new terminal![](https://i-blog.csdnimg.cn/direct/5656a4efb52f47019fb2c3ef79619d9a.png)

*备注：视频2博主的终端界面和我的有区别*

```
# 生成 SSH 密钥
ssh-keygen -t rsa -C "你的邮箱地址"
# 查看公钥
cat id_rsa.pub
```

#### 问题2.在终端输入git config -- global user.name"waner"或者git config -- global user.name"waner"报错

(dy视频2)

####

解决办法：正确输入为git config --global user.name"waner"

即git configk空格--global空格user.name"名字"

备注：不确定是否可以用""还是一定不能用，有的博主用有的博主不用。等以后再确认吧

#### 问题3.按照视频2把用户名和地址配置好了，commit时vscode还是提示确认用户名和地址,无法连接到github

解决办法：见csdn文章2，把""去掉，换成空格

```
git config --global user.name iceylia
git config --global user.enail 92439@af.com
```

#### 如何clone：

有的博主在终端

```
git clone https://github.com/用户名/仓库名.git
```

即git clone空格SSH
